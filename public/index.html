Lesson 1 — Joins

Reward: +150 XP · 🔓 Unlocks “Join master”

WITH customers AS ( SELECT * FROM VALUES (1,'Ana'),(2,'Bruno'),(3,'Carla') AS customers(customer_id, name) ), orders AS ( SELECT * FROM VALUES (101,1,50),(102,1,30),(103,2,20) AS orders(order_id, customer_id, amount) ) SELECT * FROM customers;

🎯 Task A — INNER JOIN

List order_id, customer name, and amount — one row per order. Predict the row count before you run it.

An INNER JOIN keeps only rows where the join key matches on both sides. Carla has no row in orders, so her key never matches → she drops out. Driver table = orders (one row per order).
✔ Task A cleared

🎯 Task B — LEFT JOIN THE TRAP

Order count per customer, including Carla = 0. ⚠️ COUNT(*) gives Carla 1 (it counts her customer row). You must COUNT( the right column ) so she shows 0.

LEFT JOIN keeps every customer, filling NULLs where there's no matching order. COUNT(*) counts rows (Carla still has 1 row, full of NULLs → counts 1). COUNT(o.order_id) ignores NULLs → Carla = 0. Drive from customers with LEFT JOIN.
✔ Task B cleared
